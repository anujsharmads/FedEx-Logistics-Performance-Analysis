# FedEx Logistics Performance Analysis

A data science EDA project focused on understanding how shipments move, where logistics cost increases, 
and which factors affect supply chain performance.

## What This Project Does

This project analyzes logistics shipment data to uncover patterns in:

- Shipment modes
- Product groups
- Destination countries
- Vendor dependency
- Freight cost behavior
- Shipment value and weight relationships

The goal is to turn raw logistics data into useful business insights.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Google Colab

## Key Highlights

- Cleaned and prepared shipment data for analysis
- Treated outliers using the IQR method
- Analyzed shipment mode, product group, country, and vendor patterns
- Compared freight cost across shipment modes
- Studied relationships between freight cost, weight, and line item value
- Created visualizations for clear business storytelling

## Main Insights

- Air was the most used shipment mode.
- ARV products dominated the shipment volume.
- South Africa received the highest number of shipments.
- SCMS from RDC was the major shipment source.
- Freight cost was not strongly dependent on shipment weight alone.
- High-value shipments required better monitoring due to higher financial risk.

## Business Value

The analysis can help improve:

- Shipment planning
- Cost control
- Vendor management
- Route prioritization
- Inventory and supply chain decisions

## Conclusion

This project shows how logistics data can reveal hidden cost patterns and operational risks. It helped me understand that supply chain performance depends on multiple factors, not just shipment weight or product value.
